**Приложение создано для создания промта для нейросети**.<br>
**Поддерживает архивы**: **.zip**, **.rar**, **.7z**<br>
**Пример**: Ты загружаешь архив файл с кодом "**python**" которое создано с помощью **PyCharm**. Он убирает из промто системные файлы как **.idea**, **.venv** и т.п.<br>
**Промт** будет выглядеть примерно так: "<br>
Вот мой код:<br>
example1.py:<br>
print("example1.py")<br>
app/example2.py:<br>
print("example2.py")<br>
Вот структура проекта:<br>
Проект:<br>
  example1.py<br>
  app/<br>
    example2.py<br>
Добавь в этот код способы оплаты."<br><br>
