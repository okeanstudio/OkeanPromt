## 📖 О приложении

**Okean Promt** — это десктопное приложение для Windows на **C#**, которое автоматически создает структурированные промты для нейросетей на основе вашего кода.

Просто укажите папку с проектом или загрузите архив, и приложение сделает всё за вас.

---

## ⚡ Что умеет

- Распаковывать архивы .zip, .rar, .7z
- Очищать от системных файлов (.idea, .venv, __pycache__, node_modules, bin, obj)
- Генерировать промт с кодом и структурой проекта
- Копировать промт в буфер обмена в один клик

---

## 🎯 Кому пригодится

- Разработчикам на C# для создания промтов с кодом
- AI-инженерам для тестирования нейросетей
- Студентам для отправки кода на проверку
- Командам для обмена кодом через промты

## 🚀 Как работает

Пример: вы загружаете папку с проектом.

**Было:**
```
📦 MyProject/
├── .idea/              ← удалится
├── .venv/              ← удалится
├── bin/                ← удалится
├── obj/                ← удалится
├── Program.cs
├── Utils.cs
└── appsettings.json
```

**Стало (промт):**
```
Вот мой код:

Program.cs:
```csharp
Console.WriteLine("Hello, World!");
```

Utils.cs:
```csharp
public static class Utils
{
    public static string Helper() => "Helper";
}
```

Вот структура проекта:
```
MyProject/
  Program.cs
  Utils.cs
  appsettings.json
```

Добавь в этот код способы оплаты.
```

## 📥 Установка

**Portable версия (рекомендуется):**

1. Скачайте `AI-Prompt-Builder.zip`
2. Распакуйте в любую папку
3. Запустите `AI-Prompt-Builder.exe`

**Установщик:**

1. Скачайте `Setup.exe`
2. Запустите и следуйте инструкциям

## 🖥 Системные требования

- Windows 10 или 11 (64-bit)
- Процессор 1.5 ГГц или выше
- 2 ГБ ОЗУ (рекомендуется 4 ГБ)
- 50 МБ свободного места
- .NET Runtime 6.0+ (устанавливается автоматически)

---

## 🗂 Поддерживаемые форматы

- ZIP (.zip)
- RAR (.rar)
- 7z (.7z)
- Обычные папки

## 🔧 Как пользоваться

**Шаг 1.** Выберите источник:

- Нажмите "Обзор" и выберите папку с проектом
- Или выберите архив .zip, .rar, .7z

**Шаг 2.** Настройте фильтры (опционально):

- Добавьте папки или файлы, которые нужно исключить
- Выберите язык программирования

**Шаг 3.** Получите промт:

- Нажмите "Сгенерировать"
- Нажмите "Копировать" (или CTRL+C)
- Вставьте в нейросеть (CTRL+V)
