## 📖 О приложении

**Okean Promt** — это десктопное приложение для Windows на **C#**, которое автоматически создает структурированные промты для нейросетей на основе вашего кода.

Просто укажите папку с проектом или загрузите архив, и приложение:

- 📦 Распакует архив (.zip, .rar, .7z)
- 🧹 Очистит от системных файлов (.idea, .venv, __pycache__, node_modules и др.)
- 📝 Сгенерирует красивый промт с кодом и структурой проекта
- 🤖 Подготовит идеальный запрос для ChatGPT, Claude, DeepSeek
- 📋 Скопирует промт в буфер обмена одним кликом

## 🚀 Пример работы

### Загружаете архив:
```
📦 project.zip
├── 📁 .idea/          (удалится)
├── 📁 .venv/          (удалится)
├── 📁 app/
│   ├── Program.cs
│   └── Utils.cs
├── 📁 tests/
│   └── UnitTest1.cs

```

### Получаете промт:
```
Вот мой код:

app/Program.cs:
```csharp
Console.WriteLine("Hello, World!");

app/Utils.cs:
```csharp
public static class Utils
{
    public static string Helper() => "Helper";
}
```

Вот структура проекта:
```
Проект:
  app/
    Program.cs
    Utils.cs
  tests/
    UnitTest1.cs
  appsettings.json
```

Добавь в этот код способы оплаты.
```

## 🔧 Использование

### Быстрый старт:

1. **Выберите источник:**
   - 📂 Папка → выберите папку с проектом
   - 📦 Архив → выберите .zip, .rar или .7z

2. **Настройте фильтры:**
   - Добавьте свои исключения
   - Выберите язык программирования

3. **Получите промт:**
   - Нажмите "Сгенерировать"
   - Скопируйте результат (CTRL+C)
   - Вставьте в нейросеть (CTRL+V)
